# 🐞 AfiliaBug

Plataforma completa para afiliados encontrarem **preços bugados**, criarem **links rastreáveis**, gerarem **vídeos de divulgação** e acompanharem **performance em tempo real**.

## 🚀 Como rodar

```bash
# 1. Clone o repositório
git clone https://github.com/seu-usuario/afilia-bug.git
cd afilia-bug

# 2. Crie o ambiente virtual
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# 3. Instale as dependências
pip install -r requirements.txt

# 4. Rode o app
streamlit run app.py
